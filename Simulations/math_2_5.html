Expression Engineer

Build expressions to hit target values!

From the Textbook (Page 45)
Using three 3s: (3+3)/3 = 2, 3+3−3 = 3, 3×3+3 = 12.
Using four 4s: make every number from 1 to 20!
The same digits with different operations and brackets create completely different values. That's the power of arithmetic expressions!

How to Use This Simulation

What To Do
1Pick a challenge — each one tells you exactly which digits you can use and how many.
2A target number is highlighted. Build an expression using ONLY the allowed digits.
3Use +, −, ×, ÷ and brackets ( ) to connect the digits. Tap = to check.
4When you match a target, it turns green. Try to find ALL targets in each challenge!
Try This
Four 4s → 1: Try (4+4)÷(4+4). That's 8÷8 = 1!
Four 4s → 5: Try (4×4+4)÷4. That's 20÷4 = 5!
2,3,5 → 0: Try 5−3−2. Or 2+3−5. Both work!
Key Concept
Brackets change everything! 4+4÷4+4 = 9, but (4+4)÷(4+4) = 1. Same digits, same operations, different brackets → completely different value.
