What is a Letter-Number?
A letter like a, n, or x represents an unknown or variable number. When you replace it with an actual number and compute, you're evaluating the expression. For example, if a = 23, then a + 3 = 23 + 3 = 26.

Key Concept
3d means 3 × d, NOT "3 followed by d". So if d=6, 3d = 3×6 = 18 (NOT 36!). And 10 − a when a = −4 means 10 − (−4) = 10 + 4 = 14 (NOT 6!).
