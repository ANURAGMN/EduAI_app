Creative Chitti Calculator

Build numbers using place value buttons!

The Rule
The fewest clicks to build any number equals the sum of its digits. This is because using the largest possible button for each place value is the most efficient strategy — and that's exactly the Indian place value notation!

How to Use This Simulation

What To Do
1Tap the coloured buttons (+1, +10, +100, etc.) to add to your number. Each tap adds that place value.
2Watch the bar chart change — each bar shows how many times you've filled that place value (0–9).
3Compare your "Clicks Used" with "Min Possible". Can you reach the target with the fewest clicks?
4In Challenge Mode, pick a target number from the presets and try to build it. In Free Explore, build any number you like.
Try This
Challenge 1: Build 5,072. Try using only +1000, +10, and +1. Count your clicks. Now reset and try a different combination — can you beat your score?
Challenge 2: Switch to "+1K Only" restrict mode. How many clicks to reach 1,00,000? (Answer: 100 clicks — that's how many thousands make a lakh!)
Challenge 3: Build 997. The minimum is 25 clicks (9+9+7). But try (8×100)+(19×10)+(7×1) = 34 clicks. Same number, more clicks!
Key Concept
The minimum clicks to build any number = sum of its digits. For example, 5072 has digits 5+0+7+2 = 14 clicks minimum. This works because each digit tells you exactly how many times to press each place value button — that's the Indian place value system!
